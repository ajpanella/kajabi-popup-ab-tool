# Popup Test Studio Redesign Concept

This directory is a standalone review prototype. It does not read from or write to the live popup dashboard, variants, tracking data, GitHub publishing flow, or Kajabi embed.

## Information architecture

- **Overview:** test health, live performance, recommendations, and compact variant previews.
- **Build:** one variant and one step at a time in a fixed three-pane workspace.
- **Analyze:** active-version metrics, filters, conversion rates, and event counts.
- **History:** searchable, sortable versions with restore and comparison actions.
- **Ideas:** a lightweight testing backlog organized by status.
- **Settings:** test, delivery, publishing, embed, and saved-color controls in a drawer.

## Review principles

- Keep the current feature set while reducing page-level scrolling.
- Put the editing sequence in the same order as the visitor experience.
- Keep the live preview visible while copy, form, design, or behavior changes are made.
- Separate building, analysis, history, and configuration so each workspace has one clear job.
- Reserve green for active state, readiness, and primary actions.

Publishing is intentionally disabled in the prototype.
